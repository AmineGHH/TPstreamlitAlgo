# 🌳 TP Streamlit Algo — AVL, ABR, and Heap Visualizer

An interactive **Streamlit web app** for visualizing fundamental data structures and algorithms:  
**AVL Trees**, **Binary Search Trees (ABR)**, and **Heaps (Tas Max / Tas Min)**.  
This project helps users understand how insertions, deletions, and rotations work step by step through an intuitive and easy-to-use interface.

## 🚀 Features
✅ Step-by-step AVL Tree visualization (with rotations)  
✅ Display ABR (Binary Search Tree) and Heaps (Max / Min)  
✅ Interactive controls to insert or delete nodes  
✅ Compact traversal displays `[1, 5, 80]` format  
✅ Easy-to-understand logs for each step  
✅ User-friendly IHM (Interface Homme-Machine)  
✅ Graphs generated using **Graphviz**
